# Radio role portraits

`radio_crew.png` is an unchanged original OpenAI image_gen output, 2172×724 pixels.
Four equal-width atlas columns depict Okafor, Crane, Mara and Wick's optical
instrument. No third-party photography, real-person likeness request or external
asset dependency was used. These are provisional art proposals: the canonical Story
Bible defines roles but not these physical appearances. They do not reveal Crane's
secret or later-zone lore. Wick is an instrument display, not a human character.

Import: lossless texture, mipmaps, size_limit=1024, linear mipmap filtering; runtime
uses four AtlasTextures with filter_clip. Radio renders one 56×72 frame beside an
explicit speaker label. The image does not convey essential information alone and
adds no animation, audio requirement, focus target or gameplay state. Replacing
this atlas later changes no narrative IDs, saves or portrait selection API.

Exact output identity, SHA256 and dimensions are in provenance.json. No layered
human-painted source is claimed. Project license remains pending; no additional
copyright, exclusive-rights or legal clearance claim is made. Final character-art
and likeness/quality approval requires human review.
